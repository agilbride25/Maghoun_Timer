# Thank you for taking a look at the Maghoun Timer!
---
This project was developed to perfectly time the walk from my house to my T-stop along the Boston MBTA green-line so that I could catch the train on time everytime. 
This project uses the MBTA restAPI to fetch trains arriving to the stop and going inbound into the city. 
It is also deployed on github pages, so if you want to open the link on your phone, and then save the link to the homescreen, it will act as an app that you can use to time the next train into the city! 
If you live in the maghoun square area, feel free to try it out and let me know how it fares for you!
